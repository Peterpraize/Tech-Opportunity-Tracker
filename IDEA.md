# Tech Opportunity Tracker — Idea One-Pager

## 1. Project Idea

Tech Opportunity Tracker is a web application that helps people discover and organise technology-related opportunities, including internships, scholarships, fellowships, entry-level jobs, and training programmes.

## 2. Problem Statement

Students, aspiring developers, recent graduates, and job seekers may struggle to find relevant opportunities because information is spread across multiple websites and platforms. Keeping track of interesting listings can also be difficult.

## 3. Proposed Solution

The application brings opportunity listings into one interface. Users can search by keywords, filter by opportunity category, and save listings they want to revisit.

## 4. Target Users

- Students and recent graduates
- Beginner and aspiring software developers
- Technology learners seeking training
- Job seekers interested in technology careers

## 5. Project Goals

- Make technology opportunities easier to browse.
- Help users narrow results using search and filters.
- Allow users to identify and save interesting listings.
- Provide a responsive and accessible experience on mobile and desktop devices.
- Build a foundation for future integration with an API or other data source.

## 6. Core Features

1. Opportunity listing cards
2. Keyword search
3. Category filtering
4. Save and unsave functionality
5. Empty-results feedback and filter reset
6. Responsive layout

## 7. Technology Stack

React, Vite, JavaScript, HTML, CSS, and ESLint.

## 8. Scope and Limitations

The current version uses sample demonstration data. It does not yet verify live opportunities or guarantee that any listing is available. Future development will introduce data integration, persistent saved listings, and additional application views.

## 9. Success Criteria

The application should allow users to browse opportunities, search and filter listings, save and unsave items, and use the interface at mobile and desktop widths without unnecessary horizontal scrolling.

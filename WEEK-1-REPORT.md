**Week:** Week 1 — Frontend Development

## 1. Work Delivered

- Set up the React application using Vite.
- Developed the initial Tech Opportunity Tracker interface.
- Added opportunity cards using sample demonstration data.
- Implemented keyword search and category filtering.
- Added save and unsave functionality.
- Implemented empty-results feedback and a clear-filters action.
- Improved responsive styling for mobile and desktop layouts.
- Created `README.md`, `IDEA.md`, and `WORK_PLAN.md`.
- Initialized Git and published the project to a public GitHub repository.
- Deployed the application using Vercel.
- Captured and committed desktop and mobile screenshots.
- Created and pushed the `week-1` Git tag.

## 2. Changes Following Testing

The interface was adjusted to improve its mobile layout. The developer tested the application at mobile viewport widths and checked the main interactive features.

## 3. Key Technical Decisions

- React and Vite were selected for the frontend application.
- CSS media queries were used to improve responsiveness.
- React state was used to manage searching, filtering, and saved opportunities.
- Git and GitHub were used for version control.
- Vercel was used to deploy the application.

## 4. Blockers and Risks

- The application currently uses sample demonstration data rather than verified live opportunities.
- Saved opportunities currently use application state and may not persist after a page reload.
- Further accessibility verification and automated testing remain to be completed.
